## The 30-second version

Pick a Swedish industry transition. Pick one theory from L1–L4. Narrow it to a specific case. Write a research question. Gather 4–5 newspaper articles (SvD + DN + DI), 4–5 CABS 2+ journal articles, and insights from a guest lecture. Write 1000–1500 words arguing what the theory reveals about the case. Present it in 7 minutes, alone.
