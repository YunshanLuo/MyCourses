## 3. Weekly rhythm (once the deadlines settle)

| Slot | Focus |
|---|---|
| Mon–Fri AM (2h) | Primary course of the week (usually DD2380) |
| Mon–Fri PM (2h) | ME2322 / secondary course |
| Sat (4h) | Deep work: assignments, past papers |
| Sun (2h) | Review, notes, planning next week |

**Rules that matter:**
1. Submit **2 days before every hard deadline.** DD2380 says "strict, no extensions" — believe it. Late = max grade B.
2. Every programming assignment needs the **individual Learning Journal** — code alone is not a submission, and the journal decides your grade within the Kattis band.
3. You must understand **all three** implementations — the oral exam picks one at random.
4. ME2322 is 100% reading + argument. Take notes per paper (author, claim, how it applies) — that's exactly what the oral exam quizzes, and it's the raw material for the report.
5. **Take notes during your seminar.** The peer feedback is required content for the January reflection — the cheapest mark to lose.
6. **ME2322 team members present to different feedback groups** — everyone must be able to present the whole project alone.
